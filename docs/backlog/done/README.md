## Closed backlog items (archive)

This directory contains backlog items that are no longer active:
- Done (implemented)
- Dropped (intentionally not pursued)
- Superseded (replaced by another item)

Closed items are kept for traceability:
- what was considered
- why it was done (or not done)
- how it was implemented

Do not delete closed items; move them here and update their `Outcome` section.
